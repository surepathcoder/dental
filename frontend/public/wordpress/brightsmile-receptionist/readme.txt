Adds the BrightSmile dental AI receptionist chat button to a WordPress site that already exists.

== Description ==

Dentists who already have a WordPress website do not need a new site. Install this plugin, paste the hosted app URL, and the same AI receptionist used on the BrightSmile demo appears on every public page.

Conversations, phone capture, booking and reminders stay in the clinic dashboard.

== Installation ==

1. In WordPress go to Plugins → Add New → Upload Plugin.
2. Upload brightsmile-receptionist.zip and click Activate.
3. Open Settings → AI Receptionist.
4. Paste the hosted app URL we provided (example: https://app.yourpractice.com).
5. Save. Visit the public site — the chat button is in the bottom-right corner.

== Frequently Asked Questions ==

= Do I have to change my theme? =
No. The plugin only adds the chat script.

= Where do leads go? =
To the clinic dashboard on the hosted app, not into WordPress comments or Forms.
